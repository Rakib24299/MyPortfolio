# Md. Julker Nain Rakib - Personal Portfolio

A modern, sleek, fully responsive developer portfolio built using HTML5, Tailwind CSS, and JavaScript.

## ✨ Features
- **Responsive Layout:** Optimized for mobile phones, tablets, laptops, and ultra-wide desktops.
- **Dark / Light Mode:** Smooth theme switcher with local storage persistence and system preference sync.
- **Modern UI:** Glassmorphism card effects, animated RGB gradients, and smooth hover micro-interactions.
- **Mobile Navigation:** Interactive hamburger menu for smaller screens.
- **Sections:**
  - **Home:** Hero section with animated introduction and social links.
  - **About:** Personal bio, academic timeline, hobbies, and downloadable CV.
  - **Skills:** Categorized technical and soft skill badges.
  - **Works:** Showcase of web development and software engineering projects.
  - **Contact:** Contact information and interactive message form.

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript
- **Icons & Fonts:** Font Awesome 6, Google Fonts (Poppins)
- **Deployment Ready:** Static files compatible with GitHub Pages, Vercel, Netlify, etc.
